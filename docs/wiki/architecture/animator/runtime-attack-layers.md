# Runtime attack layers

The shared `AnimationEvaluator` samples sorted TRS tracks with a short linear scan up to 64 keys and `std::upper_bound` for denser baked tracks. The latter finds the outgoing segment in logarithmic time without a per-actor cursor/cache, so reverse playback, scrubbing and live clip edits use the current data directly. Exact key times (including duplicate times), outgoing Linear/Smooth/Stepped interpolation, empty-component bind-pose fallback and full-precision joint matrices retain the same behavior. Playback frequency and animation quality are unchanged; this reduces CPU sampling work across Player, Editor, Animator and attack overlays.

Within each `AnimationSystem::Update`, states share a pose when they refer to the same skeleton and clip array and have exactly matching base clip/time, layer clip/time, bone mask and anchor. The immediately preceding pose is checked first, with a per-update hash table finding matches elsewhere in the state list. Multi-mesh characters therefore avoid repeatedly evaluating their complete skeleton for every material/prop mesh. This reuse lasts only for that update, never quantizes time, and excludes procedural skinned strips with per-node width scales. Every state still advances its own clocks and root motion and owns its joint matrix array. Unique poses are evaluated before shared-pose copies and scene updates; crowds can use up to four worker chunks, while small scenes stay serial.

`AnimationSystem` supports one independently timed 3D override layer per animated mesh node. Lua `animation.play_layer(node, clip_name, bone_names, loop?, speed?, start_time_seconds?)` requires an existing base animation, validates the complete explicit bone mask before replacing a layer, and samples the same saved TRS data as ordinary playback. The optional start time defaults to zero; looping layers retain its unwrapped elapsed value and wrap the sampled pose, while non-looping layers clamp it to the clip range. Nonfinite offsets fail without replacing the active layer. This allows randomized follow-up clips to carry frame overshoot through a shot boundary without restarting locomotion or losing cadence. `animation.set_speed` controls the base clock; `animation.set_layer_speed` changes only the layer clock without resetting its phase. `animation.set_layer_mask(node, bone_names)` validates and replaces an active layer's explicit mask, evaluates it immediately, and preserves its clip, elapsed time, speed and loop state. Empty or unknown masks fail without modifying the layer. This lets a standing strike include its footwork, then return the legs to independent locomotion while moving without restarting the attack or its hit markers. A base `animation.play` switches locomotion while retaining an active layer. Pause/stop on the node pauses both; a base speed of zero freezes the base while the layer continues. Layer root motion never moves the node.

The mask replaces complete **rig-space** joint poses after evaluating both clips. Unselected descendants retain the base clip's global pose even when an ancestor is selected: an attacking body cannot drag the running feet. Include a complete interacting group (torso, arms, hands, held prop, attached head/scarf) to retain authored grip contacts. This is a full-strength override for a named bone set, not an additive or weighted blend; planar/spline rigs are rejected. The ordinary single-clip evaluator and saved asset format are unchanged.

The optional seventh `animation.play_layer` argument, `anchor_bone`, aligns the layer's named anchor to that bone in the base pose. The selected group is transformed by `base_anchor * inverse(layer_anchor)` before replacement; unselected bones stay in the base pose. Anchoring a running attack's upper body to `pelvis` removes the attack clip's baked pelvis bounce and follows the independent locomotion clock while preserving the authored arm/weapon contacts. An omitted or empty anchor keeps ordinary rig-space replacement. An unknown anchor fails without replacing the active layer; a singular overlay anchor skips alignment for that evaluation to avoid inverting a collapsed transform. The pose cache includes the anchor index, so otherwise identical anchored and unanchored layers cannot share matrices. `animation.get_layer_state(node).anchor` reports the bone name, or an empty string for an unanchored active layer.

`animation.get_bone_position(node, bone_name)` reads the currently evaluated joint origin in rig space, before the mesh node's world transform. It returns `nil` for an invalid node, missing bone, or unavailable pose. Scripts can use it to keep effect attachment positions consistent with a composite pose; it does not advance or resample animation.

`animation.get_layer_state(node)` returns `active`, `clip`, wrapped `time`, unwrapped `elapsed`, `duration` (times in clip seconds), `speed`, `loop`, and `playing`. Pair `elapsed` with `animation.get_markers(node, clip_name)` to detect every impact across loops or large frame steps. A non-looping layer holds its final pose until `animation.stop_layer(node)` restores the base pose immediately. Nonfinite rates, missing clips/bones, and empty masks fail without disturbing the active layer. `PlayLayer`, `SetLayerSpeed`, and `StopLayer` are the corresponding C++ entry points in `Phasma/Runtime/Code/Systems/AnimationSystem.*`; the Lua surface is in `Script/Bindings/Animation/AnimationBindings.cpp`.

The ATH Farmer uses two equally spaced impact markers per left/right Attack loop. Its game controller sets layer speed to `clip_duration / (2 * effective_attack_interval)`, preserving the Run stride during attack-speed buffs. This runtime overlay is separate from the Timeline's `timeline.layer` operation, which bakes selected channels into another saved clip.
