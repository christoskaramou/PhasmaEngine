# Runtime 2D Skinned Procedural Animation

The runtime can generate a flat skinned 2D strip through `primitives.skinned_strip_2d(width, height, segments, bones)`. The primitive builds a lightweight XY grid strip, assigns local cubic curve-station joint weights along the strip length, creates a chain skeleton, marks the mesh as skinned, and includes a simple `wave` animation clip. New strips default to 24 deformation bones, and lower requested counts are lifted up to the mesh segment count or 24, whichever is smaller, so tight bends have enough frame samples while still using the existing GPU skinning path instead of per-frame vertex-buffer rewrites.

`AnimationSystem` applies a clip's extracted root-motion track (`AnimationClip::rootMotion`, authored in PhasmaAnimator) to the node the clip plays on: each update moves the node by the track's delta since the last applied clip time - through the loop seam when the clip wraps - taken from the carrier's channel space into the node's own space through the carrier's parent bind global and prefix, then into the parent's space by the node's basis; a scrub (`SetPlaybackTime`) teleports the pose, never the node. `animation.set_root_motion(node, bool)` / `animation.get_root_motion(node)` toggle it per node (on by default); `animation.get_markers(node, clip?)` returns the clip's ruler markers as `{name, time}` in seconds (the playing clip when none is named) and `animation.get_time(node)` the playhead in seconds, so a script can fire footsteps or hits on them.

Lua can also drive generated strip skeletons procedurally with `animation.set_joint_rotations_z(node, rotations, stretchScale, widthScales)`, where `rotations` is a 1-based array of local Z rotations in radians, `stretchScale` is optional, and the optional `widthScales` table tapers or bulges the strip thickness per joint. The helper is intentionally scoped to `skinned_strip_2d` nodes, evaluates those local rotations and child-bone translation stretch over the strip bind pose, derives smoothed tangent frames from neighboring joint positions, applies local width scales in those frames, writes final joint matrices into the selected node runtime, stops clip playback for that node, and marks the node dirty for the normal GPU upload path. `animation.solve_strip_ik_2d(node, targetLocal, iterations, maxBendDegrees, maxStretchScale, jointInfluences, widthScales)` uses a smooth bend-limited planar chain solver to aim the strip toward a node-local XY target and emit local Z rotations without accordion-style folding when the target is inside reach; the optional bend limit defaults to 60 degrees, the optional stretch limit defaults to 1.5x, and the optional 1-based `jointInfluences` table uses `1.0` as normal bend, `0.0` as stiff, and values up to `2.0` as extra flexible. Width scales use `1.0` as normal thickness and are clamped to `0.05`-`3.0`. The solver clamps very close targets and total arc to avoid unstable loops. `animation.get_joint_count(node)` exposes that node's skeleton count for scripts sizing procedural pose arrays; the no-argument form returns the scene's maximum joint count for compatibility.

`Scripts/samples/skinned2d_wave_sample.lua` is a raster-mode orthographic smoke sample that creates a skinned strip and drives its joints from a Lua sine wave each frame. `Scripts/samples/skinned2d_ik_sample.lua` creates the same kind of strip plus a moving target marker and drives the chain through `animation.solve_strip_ik_2d`, including stretch when the target moves beyond bind-chain reach. The editor Mesh creation and mesh-component attach menus expose `Skinned Strip 2D`, and MCP `add_mesh_to_node` accepts `skinned_strip_2d`; attached skinned primitives keep their source model so the node can still resolve the strip skeleton and clips. Selecting a generated strip shows a Properties panel for live bind-pose reset, local IK target solving, bend-limit and stretch-limit controls, current pose stretch, per-joint IK bend influence sliders, per-joint width scale sliders, per-joint Z rotation sliders, and a viewport-draggable IK target over the same procedural pose path. Editor-authored strip rotations, IK target, solver settings, bend direction, stretch scales, joint influences, and width scales are persisted per node in scene and snapshot JSON under `skinned_strip_2d` and restored through the normal joint-matrix upload path. Skinned meshes are already skipped by the ray-tracing BLAS/TLAS build path, so this first 2D deformation surface remains raster-first while true free-form soft bodies wait for dynamic per-mesh vertex-subrange updates and a solver.

The scene caches the maximum joint count across owned models and invalidates that cache when model ownership changes. Render passes and joint-buffer sizing use this aggregate as a capability bound, while each node still allocates and writes joint data with its own skeleton's bone count and storage offset. Non-skinned nodes do not reserve joint-tail padding in that packed buffer, so the shader skinning paths rely on non-skinned vertex streams keeping zero joint weights before any joint matrix load.

Skinned visibility bounds follow the current pose. `SkinnedBounds` caches each mesh's bind-space vertex bounds per influencing joint; dirty-node updates transform those bounds using the same root-corrected matrices as the vertex shaders. The union also includes unweighted vertices and an expansion for signed spline weights. Geometry uploads invalidate the cache, including Animator weight-paint updates. CPU world bounds and GPU frustum, Hi-Z and shadow culling use the resulting instance bounds. The 144-byte `NodeGpuData` header retains its joint offsets: byte 132 points to an optional 32-byte world AABB after the joint tail, uploaded in the same frame buffer as the pose. Static nodes keep a zero pointer and their existing per-mesh bounds. Skinned nodes currently cull their mesh references against the whole node's bounds; separate bounds per reference are only needed if profiling shows excessive overdraw on large multipart rigs. The model format and authored animation data are unchanged. The internal `SkinnedBounds.h` relies on `PhasmaPch.h` for common standard-library and math definitions, retaining only its `<span>` and `API/Vertex.h` includes.

Non-skinned procedural primitive nodes created through Lua (`primitives.cube`, `primitives.sphere`, `primitives.cylinder`, and the other simple factories) share scene-local geometry once the first matching primitive shape has been uploaded. Later primitive nodes still receive their own mesh/material record so `material.set` and texture assignment stay per node, but their mesh records point at the cached vertex/index ranges instead of appending duplicate geometry and forcing another full geometry-buffer upload. Runtime pools that need frequent hide/show should prefer offstage/tiny transforms over `set_enabled`, because enabled-state changes rebuild the scene draw/instance lists.
